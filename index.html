Professional Self-Assessment

When I began my journey in the computer science program, I had a very strong interest in the field of computer science, but only a general idea of the dept of the field and what it meant to be a computer scientist. Every course that I took within the computer science program deepened my understanding of the field, and pushed me harder and harder to challenge myself and develop my strengths as a computer scientist. This self-assessment reflects how far I have come on my journey, and how my goals and values have been shaped by the experiences that I have had in the program.


In the early stages of the program, classes like Data Structures and Algorithms, Programming Languages, and Operating Platforms introduced me to concepts that I had not never encountered before, while serving as primers for a field I was becoming increasingly excited to explore. As I progressed through the program, more specialized courses like Full Stack Development and Secure Coding helped me develop a solid skill set in those areas.


Though my coursework and the development of my ePortfolio, I have become increasingly more prepared for a career in the field of computer science. Building interesting projects relevant to my interests has given me practical experience by applying the concepts that I have learned to real world problems.


Outside of course work, completing the Scrimba full-stack developer program and being a part of the 100Devs community has further strengthened my technical foundation and exposed me to industry-style workflows. I also completed the Android Development CodePath course, which served more to give me experience collaborating with other developers on a project. My background as a retail manager has also contributed valuable soft skills including communication, adaptability and leadership, which are skills that will translate very well into a software development team environment.


Collaborating in a Team Environment

Throughout the program, I gained a strong understanding of how modern software development teams operate. I learned how teams use Scrum to organize work, assign tasks, and manage challenges through clear communication and conflict resolution. I also developed hands on experience with version control, which allowed me to collaborate effectively, track changes, and contribute to a shared codebase.


Communicating with Stakeholders

While completing my coursework and projects, I was able to gain academic experience in effective communication with both technical and non-technical stakeholders. Many of the assignments I completed in the program involved gathering requirements, explaining design decisions, and documenting my work in a way that a broad array of people could understand it. The work I have completed has prepared me to effectively communicate progress and expectations, as well as technical details of software development projects.


Data Structures and Algorithms

Data Structures and Algorithms has been the most enjoyable part of learning software development for me, as it has allowed me to better understand why certain solutions are better than others, and how real world software is shaped by efficiency. Working with data structures like arrays, linked lists, trees and hash maps, as well as deep diving into sorting, searching, and recursive algorithms has deeply strengthened my critical thinking ability and my approach to problem solving. I have shown use of these skill in my academic projects, and I will continue to build on them moving into a professional career.


Software Engineering and Databases

Before attending SNHU and pursuing software development, I had little understanding of the intricate nature of databases and how they are connected to the software application as a whole. My coursework has given me a much deeper understanding of how databases are designed and built, and how to maintain them within a software system. I also learned about core software engineering principles including but not limited to modular design, testing, and security practices. These principles will help me approach development in a more structured way. Although there is still much more for me to learn, I now have a strong foundation in both software engineering and database concepts and I feel confident that I will be able to utilize this knowledge while building and maintaining future applications.

Security

The concept of software security gave me a major shift in perspective for how I look at writing code and designing software systems. In the beginning I focused most of my efforts on simply getting things to work. After having spent more time learning software security, I now thing about systems in terms of how they can be misused by bad actors, and what steps can be taken to mitigate these issues and protect users data. I have learned that building software systems requires more focused attention on things like input validation, error handling, and authentication, and not just whether or not the software will function for the user.

Summary

The following artifacts are meant to showcase how I have learned and am able to apply core concepts of computer science to real world software. The enhancements that I created for this project are each meant to highlight a specific area of my Technical ability.


The Software Engineering enhancement is showcased by adding an item entry form that allows the user to add items, and I also created functional increase/decrease buttons, and a Delete button.


The Data Structures and Algorithms enhancement was completed by adding a search form, as well as functionality to prevent duplicate entries into the list.


The Databases enhancement connects the application to the SQLite database allowing for persistent data after the application is restarted

Enhancement One: Software Engineering

For the first enhancement of my project, I expanded the functionality of the application by implementing a form for adding items to the list, a button for deletion and buttons for quantity adjustment. This task required migrating the interface from the original TableView, to a new RecyclerView. This made it possible for the application to scale in a more dynamic way, and allow for a larger list to be created. The controls to increment and decrement the quantity of the items in the list was a nice UI addition as well.

This enhancement presented me with a meaningful challenge, as this was my first time revisiting both this project, and Android development since completing CS-360 at SNHU. The workflow and architecture of Android development is very different than the React-based development that I focus on today, which made this a valuable opportunity for me to revisit these concepts and become more versatile as a developer today.

A snippet of the onClickListener that I created for the addItemBtn

Enhancement Two: Data Structures and Algorithms

The purpose of the second enhancement for this project was to focus on DSA. For the enhancement, I implemented a search feature that allows the user to quickly filter through items on the list by typing the item name into a newly added form. This form is connected to a TextWatcher method that looks for changes in the search form, and updates the list by calling the filterList() function. This feature enhances the usability of the app, especially as the app grows larger, by giving users an effecient method locating items

In addition to the search feature, I also implemented a linear search function to prevent duplicate entries if the user attempts to add the same item twice. This allows for a cleaner more accurate inventory management system.

This enhancement required some research on the part of setting up search functionality within the Android development environment. The linear search function itself was simple enough, however integrating it into the Android dataflow had its challenges.

A snippet of the addTextChangedListener using a TextWatcher to monitor changes in the search bar

Enhancement: Databases

For the third and final enhancement for this artifact, I integrated the project with an SQLite database, which is a lightweight relational database engine built into Android. This addition enable to application to have persistant data for items, including the names and quantity of items. This allows the data to stay intact even after the application is closed and reopened.

The enhancement was especially valuable for my learning, as I had limited experience working with relational databases outside of my school projects, an most of my personal projects use non-relational database systems. Implementing the database layer, working with the DatabaseHelper class, and connecting to the SQLite API provided meaningful hands on experience with structured data management.
